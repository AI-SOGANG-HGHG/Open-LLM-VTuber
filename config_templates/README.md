
# Config Template

This directory contains the default configuration files. One of the configuration file, `conf.default.yaml` by default, will be copied to the root directory of this project as `conf.yaml`.

Do not modify the content of these template unless you are contributing to this project.

The team example `conf.gemini.example.yaml` uses Gemini API, CPU SenseVoice, and Korean Edge TTS. Copy it to the local, ignored `conf.yaml` and set `GEMINI_API_KEY` before starting the server. See [Windows setup](../docs/local-gemini-setup.md). This example does not change the upstream defaults.
