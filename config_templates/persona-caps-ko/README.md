# Persona-CAPS 한국어 규칙 166개

`beck_2022_v2.ko.jsonl`은 Persona-CAPS 저자들이 공개한 `beck_2022_v2` 코퍼스의 한국어 번역본이다. 원본 그룹 파일 10개를 한 파일에 모았고, 각 규칙의 `situation`과 `behavior`를 한국어로 번역했다. 규칙 ID, Big Five 축, 방향, 원본 감정 라벨 및 관찰 근거(`provenance`)는 원본 값을 보존했다. Studio는 이 파일에서 상황과 행동 문장을 읽는다.

**이 데이터 파일의 라이선스는 CC BY-NC 4.0이다.** 비상업적 목적으로 이용·번역·재배포할 수 있으며, 재배포할 때는 출처, 라이선스 링크, 변경 사항을 표시한다. 이 안내는 데이터 파일에 적용된다. 저장소 소스 코드의 라이선스는 루트의 MIT 고지를 따른다. [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)
