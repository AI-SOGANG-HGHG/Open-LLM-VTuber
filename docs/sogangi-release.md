# 서강이 로컬 제품화 기록

기준일: 2026-11-03. 브랜치 `work/local-experiments`. 실제 Cubism 중립·기쁨·화남·놀람 표정과 눈·입·작은 정면 고개 기울기·상체 호흡·오른팔 인사를 대화 화면에 연결한 로컬 개발 버전이다. Live2D가 기본이며 SVG를 선택하거나 로드 실패 시 SVG로 복구한다. 입체 회전·디포머 계층·나머지 감정 원화와 외부 배포는 남아 있다.

## 실행과 검증

저장소 루트에서 기존 `.venv`와 키가 들어 있는 로컬 `conf.yaml`을 사용한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\restart-local.ps1 -OpenBrowser
# 코드와 백엔드 검사, API 호출 없음
powershell -ExecutionPolicy Bypass -File tools/check_sogangi.ps1
# 실행 중인 서버와 선택적 Playwright 환경 필요. API 호출 없음
powershell -ExecutionPolicy Bypass -File tools/check_sogangi.ps1 -WithBrowser
```

앱: <http://localhost:12393/web-tool/sogangi/>. 검사는 서버를 임의 종료하거나 의존성을 자동 설치하지 않는다. 선택적 브라우저 환경은 [검사 안내](../tests/browser/README.md)를 따른다.

실제 Live2D 대화: <http://localhost:12393/web-tool/sogangi/>. 이전 SVG 선택을 바꾸려면 설정에서 Live2D를 선택하거나 <http://localhost:12393/web-tool/sogangi/?avatar=live2d>를 연다. 설정과 URL의 명시적 선택은 브라우저에 저장하며 다음 일반 주소에서도 적용한다. 현재 모델은 눈/입·고개·호흡·팔·표정 7개 파라미터를 연결했다. 손 흔들기 버튼으로 1.6초 인사를 재생한다. SVG는 별도의 고개·시선·팔 동작을 제공한다.

## 이번 구현

| 영역 | 동작 |
| --- | --- |
| 사용자 설정 | 음량·재생 속도·배경·큰 글씨·움직임·음소거를 즉시 적용하고 브라우저에 저장. 이미 재생 중인 음성에도 음량/속도 반영. |
| Live2D 대화 | 실제 Core 눈·입 파라미터에 깜빡임·짧은 기쁨 반응·음성 크기 값을 전달. 종료/중단/음소거 시 입 닫힘. 재생 중 SVG↔Live2D 전환에도 음성과 요청을 재시작하지 않음. |
| 렌더러 복구 | 모델 로드 실패·WebGL 컨텍스트 상실 시 SVG로 복귀하고 재시도 제공. 늦은 로드가 끝난 발화의 입 움직임을 재생하지 않음. 대화 기록과 초안 유지. |
| 대화 이어가기 | 이 탭의 기록 ID와 초안을 sessionStorage에 보관. 새로고침/재연결 시 서버 기록을 다시 불러와 Agent 문맥과 화면을 복원. |
| 연결 복구 | 1·2·4·8·15초 간격으로 최대 5회 자동 재연결. 질문을 자동 재전송하지 않으며, 수동 재연결과 온라인 복귀를 지원. |
| 질문 복구 | 실패한 질문을 초안으로 다시 넣는 버튼 제공. 사용자가 작성 중인 다른 초안을 덮어쓰지 않으며 확인 후 직접 전송. |
| 기록 사용 | 최근 메시지 내용으로 전체 목록 검색, 화면은 30개씩 표시. 현재 대화의 한글 UTF-8 텍스트 내려받기. |
| 저장 안정성 | 임시 파일에 저장·flush/fsync 후 교체. 실패 시 이전 JSON 유지. 손상된 원문을 빈 기록으로 덮어쓰지 않음. |
| 복원 실패 | 없거나 손상된 기록은 명시적 history-error 응답. 확인 전 현재 Agent 기억/기록 ID를 바꾸지 않음. 재접속 중 복원이 실패하면 기존 파일을 유지하고 새 대화로 진입. |
| 경로 검사 | 상위 경로·구분자·Windows 장치 이름 등을 거부하고 실제 기록 파일의 디렉터리 포함 관계를 확인. |
| 답변 일치 | 문장 우선 표시 클라이언트는 화면과 같은 태그 정리·문장 간격으로 저장. 기존 클라이언트의 누적 형식은 유지. |

설정은 같은 origin의 브라우저에, 초안과 마지막 기록 ID는 해당 탭에 저장한다. 브라우저 저장소 차단/용량 부족 시 앱 사용을 막지 않고 저장 실패를 표시한다. 원문은 서버의 `chat_history/<conf_uid>/` JSON에 있다. UID는 기존 기록 호환을 위해 `sogangi-prototype-v1`을 유지한다.

## 확인한 것

- 코드 검사와 백엔드/평가·모델 도구 회귀 **32개**, 브라우저 대화/표정 기능 **19개**와 제품 사용 기능 **14개**, 실제 Cubism/제작 자료 검사 **5개**, 원화/전환·가져오기 자료 검사 **4개**, 동작/팔 키폼 조합 **2개**, 표정 모델/파일 **2개**, Live2D 대화 검사 **13개** 통과. 브라우저 합계 **59개**.
- [표정 모델](../live2d-models/sogangi-expressions/README.md)의 중립·기쁨·화남·놀람을 실제 Core에서 확인했다. 표정 파일 4개, 문장 재생 순서·음소거·중단·SVG 복귀·동작 줄이기와 독립 립싱크를 검사했다. 추가 서비스 API 호출은 없었다. 이는 태그 연결/재생 검증이며 모델의 감정 선택 적절성은 별도 페르소나 평가 범위다.
- 오른팔/호흡 중간 자세 12개에서 큰 연결 성분 수를 유지하고 눈·입·고개와 동시에 움직인 뒤 정확히 초기화했다. 대화 중 인사·중복 클릭 무시·API 미호출·중단/새 대화/모드/동작 줄이기 취소와 PC/모바일 좌우 끝 자세의 잘림 없음도 확인했다. [인사 모델](../live2d-models/sogangi-greeting/README.md)은 기존 팔의 통째 회전이며 팔꿈치/손가락을 분할한 리깅은 아니다.
- 확장 모델은 기존 기준 모델과 중립 픽셀이 정확히 같으며 고개/호흡과 눈/입을 동시에 조작할 수 있다. 앱/OS 동작 줄이기의 고개·호흡 정지와 오디오 립싱크 유지를 실제 Core·브라우저 오디오 시계로 확인했다. [확장 모델](../live2d-models/sogangi-motion/README.md)의 기본 ArtMesh 조합 방식이며 디포머/입체 회전 검수와 구분한다.
- 별도 가져오기용 PSD는 9개 그룹·24개 파츠의 투명 여백을 줄이고 원본 좌표·픽셀을 보존했다. 다른 PSD 판독기와 실제 Editor에서도 확인했다. 첫 설치는 UAC에서 취소됐으나 보이는 설치창으로 다시 진행해 Cubism 5.1.03 설치·실행을 완료했다.
- 눈·입의 작은 입력 변화에서 원화가 갑자기 교체되던 부분을 연속 전환으로 개선했다. 실제 SVG 렌더 픽셀 비교로 이전 임계값 부근의 연속성을 검사했다. 정지·음소거·중단의 입 닫힘은 기존 회귀 검사에서도 통과했다.
- [원화 비교 화면](http://localhost:12393/web-tool/sogangi/art-review.html)에 7개 자세와 어깨/얼굴 확대를 추가했다. 별도 어깨 후보 PSD는 정면 보존·26개 레이어 왕복을 검사했지만 자세별 보이는 효과가 없어 현재 앱에는 채택하지 않았다. [원화 인계 자료](sogangi-art-handoff.md)에 측정 오차와 미검증 범위를 기록했다.
- 제작 준비 PSD는 24개 레이어의 이름·가시성·좌표·픽셀 왕복과 투명 미리보기를 확인했다. 실제 브라우저 다운로드 ZIP의 PNG 24개, PSD 헤더와 해시도 검사했다. 여백/그룹 정리본은 실제 Cubism 가져오기도 확인했다.
- 실제 PSD 경계를 바탕으로 피벗/계층 9개·보완 영역 6개·파라미터 연결 10개의 좌표도를 만들었다. 피벗과 보완 영역은 제안이며 새 원화를 그린 결과가 아니다.
- 기존 Mao와 실제 서강이 최소 MOC3를 별도 검수실에서 WebGL로 표시했다. 서강이는 24 Drawable·27 표준 파라미터 중 눈/입 3개가 연결됐으며 한 장의 2048 텍스처를 사용한다. 실제 픽셀 변화·기본값 복귀의 정확한 일치·모바일을 확인했다. cmo3도 Editor에서 재열기했다. [모델 파일과 검증 범위](../live2d-models/sogangi-minimum/README.md), [재현 안내](sogangi-rigging-integration.md)를 따른다.
- 11월 3일 실제 인사 요청 한 번으로 기쁨 태그→SVG 표정→음성/입 움직임을 확인했다. 첫 문장 3.0초·첫 음성 4.3초였고, 문장 우선 표시와 새로고침 후 기록/초안 복원도 통과했다. 빠른 응답을 보장하는 표본은 아니다.
- 이후 실제 Live2D 대화 모드에서 인사 한 번을 요청했다. 첫 문장 0.7초·첫 음성 1.9초, 실제 Core 입 벌림 최대 1·종료 후 0, 음성 문장의 기쁨 표정·완료 이벤트 1회·요청 ID 일치와 새로고침 후 대화/초안/Live2D 복원을 확인했다. 물리 스피커 청취나 지속적인 응답 속도를 검증한 결과는 아니다.
- 여섯 화면 크기에서 가로 넘침·입력창 위치·말풍선과 설정 창의 잘림 검사 및 캡처.
- 실제 Chrome의 Gemini 응답→음성 재생→입 움직임과 종료, 새로고침 후 서버 기록/초안 복원 검사.
- 취향을 알려준 실제 대화를 저장한 뒤 새로고침하고, 색 이름을 힌트로 주지 않은 재질문에 "민트색이지!"라고 답하는 것까지 확인했다. 문장 간격/태그 정리 불일치는 실제 검사에서 발견해 수정했다. 수정 후 해당 실행의 첫 문장은 1.6초·첫 음성은 2.8초였다.
- 모델 API 없는 합성 브라우저 검사에서 대화 100회 후 메시지 200개 복원, 재연결 10회 중 새 기록/중복 요청 없음, 기록 1,000개 목록의 분할 표시/검색을 확인했다. 수 시간 실제 사용이나 모델 100회 호출을 수행했다는 뜻은 아니다.
- 가상 마이크 음원→브라우저 녹음→16kHz WAV→실제 ASR에서 한국어 전사 HTTP 200과 녹음 종료 확인. 물리 마이크/스피커 검증과 구분한다.
- 페르소나 기준 6개 시나리오와 정정 대화 포함 8개 입력을 실행했다. 초기 제공자 오류로 중단된 결과를 보존하고 선택 시나리오로 재검증했다. 도움·응원에서 비웃는 태그가 관찰돼 persona를 수정하고 해당 2개 시나리오를 다시 확인했다. 상세는 [페르소나 평가](sogangi-persona-evaluation.md).

실제 응답 시간은 이번에도 변동했다. 한 번은 첫 문장 18.7초·첫 음성 20.5초였고, 다른 요청에서는 더 짧았다. 재생 속도 설정은 음성 재생 길이를 바꾸며 모델의 응답 대기 시간을 줄이는 기능은 아니다.

## 완제품의 남은 조건

1. **서강이 Live2D 확장:** 눈·입·작은 정면 기울기/호흡·오른팔 인사 cmo3/moc3와 대화/중단 연결은 완료했다. 현재 기본 ArtMesh 조합을 고개/몸 변형용 메시·디포머로 개선하고 입체 회전에 필요한 원화를 검토해야 한다. 팔꿈치·손가락 분리, 미지원 감정 원화와 추가 모션 파일도 남아 있다. [원화 인계 자료](sogangi-art-handoff.md)와 [제작 설계](sogangi-live2d-plan.md)를 사용한다.
2. **장기 사용:** 실제 하드웨어 마이크·스피커, 수 시간 연속 사용, 재부팅/절전/실제 네트워크 변경과 다양한 모바일 키보드의 확인이 남았다. 현재 자동 검사는 이를 대체하지 않는다.
3. **사용자 분리와 서버 배포:** 같은 캐릭터의 디스크 기록은 같은 폴더를 사용한다. 로그인·기록별 권한·HTTPS·AWS/Docker 배포와 복구·백업 검증은 아직 남았다. 이번 파일 경로 검사를 사용자 인증으로 해석하지 않는다.
4. **개인화와 게임/방송:** 현재 문맥 기반 기억을 장기 선별 기억/RAG로 구현한 상태가 아니다. Minecraft·방송 어댑터와 행동 결과 검증도 별도 구현이 필요하다.

이 기록의 검증 범위는 로컬 개발 환경이다. 2026-11-04 사용자 요청으로 `work/local-experiments`의 변경을 로컬 커밋으로 정리한다. API 키·개인 대화·Editor 로컬 설정 캐시는 커밋에서 제외하며, 원격 push와 main 병합은 별도 작업이다.
