# 공개 벤치마크 — 실행 범위와 보존 상태

2026-11-02. 사용자는 전체 검색 검사와 유형별 소규모 평가부터 진행하도록 선택했고, 이후 API 한도 소진 시 평가를 멈추고 앱 응답 파이프라인 설계로 넘어가도록 요청했다. 추가 API 실행을 중지했으며 아래 완료 항목과 체크포인트를 보존했다. 전체 500문항의 Mem0·응답·공식 채점을 완료한 결과가 아니다.

규약과 데이터 출처: [평가 프로토콜](memory-benchmark-protocol.md). 재현·재개 명령: [BENCHMARKS.md](../experiments/memory/BENCHMARKS.md).

## 완료한 검사

| 검사 | 실제 완료 범위 |
|---|---|
| LongMemEval-S cleaned 검색 | 공식 데이터 500문항, 최근 chunk·SQLite BM25 각 500행 |
| LongMemEval 응답 기준선 | 고정 7유형 각 1문항, 최근 문맥·BM25의 14개 답변 생성 |
| LongMemEval 실제 Mem0 | 정정 유형 `42ec0761`의 전체 이력 18블록 수집·103개 추출 항목 기록·응답 1개 생성 |
| heard-bench 한국어 검색 | 원문 2,046개와 정답 70문항 연결 확인. 질문 시각/인물 제한 후 사실 64문항 × 2방식 |
| heard 한국어 응답 | 고정 5유형 × 2방식 = 10개 응답 생성 |
| MemOps 인접 대화 표본 | 5개 작업 유형 각 1문항, 전체 근거와 Mem0 추출 비교 10개 응답 생성 |
| 보조 judge 대조 검사 | 별도 `gemini-3.5-flash` 요청 모델에서 16/16 통과 |
| 독립 보조 judge 재채점 | 기존 기준선 답변 14개 중 4개만 재채점 후 일일 한도 소진. 완전한 점수 없음 |

최초 보조 판정은 `gemini-3.5-flash-lite`를 사용했다. 한국어의 적절한 응답 보류를 오답으로 판단한 사례가 있어, 그 판정을 확정 정확도로 사용하지 않는다. 공식 기본 GPT-4o judge의 자격증명은 현재 설정되지 않았다.

## 전체 검색에서 관찰한 수치

정답이 있는 470문항에 대해, top-10 chunk와 24,000문자 예산을 적용한 후 계산했다. 응답 보류 30문항은 근거 hit의 분모에서 제외했다.

| 검색 방식 | 모든 정답 근거 세션 hit | 모든 정답 근거 발화 hit |
|---|---:|---:|
| 최근 chunk | 8/470 = 1.7% | 2/470 = 0.4% |
| SQLite BM25 | 385/470 = 81.9% | 315/470 = 67.0% |

세션을 찾았다는 것과 실제 근거 발화를 찾았다는 것은 다르다. 발화 hit도 긴 발화의 일부 chunk만 포함할 수 있다. **위 수치는 답변 정확도와 공식 리더보드 점수가 아니다.**

한국어는 정답 근거 발화 회수 비율의 문항별 평균이 최근 문맥 약 8.0%, 어휘 검색 약 40.4%였다. 소규모·특정 영역 자료이고, 한국어 형태 분석/의미 검색을 갖춘 최적 검색기를 사용한 결과도 아니다.

## 제한과 중단 상태

- 실제 임베딩 오류에서 분당 30,000토큰 한도를 확인했다. SDK가 감싼 429도 구분하여 대기·재시도하고 완료한 블록은 보존했다.
- 독립 judge의 구조화된 429에는 일일 요청 20회 제한이 표시됐다. 요청 모델 이름은 `gemini-3.5-flash`, 해당 응답의 할당량 모델 표시는 `gemini-3.6-flash`였다. 대조 16개와 재채점 4개 이후였으며, 일일 한도를 분당 제한처럼 계속 재시도하지 않도록 보완했다.
- 유형별 Mem0 실행은 진행 중 중단했다. 응답 보류 문항 `gpt4_93159ced_abs`의 18블록 중 12블록까지 수집됐고, 정정 유형의 완료 결과와 기준선 답변들은 재사용 출처를 남겨 연결했다. 이를 7유형 전체 Mem0 완료로 계산하지 않는다.
- 앱의 Agent/세션·기본 설정·음성 경로는 이 평가 도구로 변경하지 않았다. 공식 데이터에서의 페르소나 효과 검증도 아직 수행하지 않았다.

## 로컬 산출물

- `tmp/memory-benchmarks/manifest.json`: 고정 버전·바이트 수·해시·라이선스.
- `tmp/longmemeval-retrieval-500-turn-metrics/`: 최종 세션/발화 검색 집계.
- `tmp/longmemeval-live-baselines7/`: 기준선 14응답·최초 보조 판정·공식 CLI용 hypotheses.
- `tmp/longmemeval-mem0-update1/`: 전체 이력의 Mem0 수집 결과·응답.
- `tmp/longmemeval-live-stratified7/`: 재사용 출처와 중간 수집 상태. 평가가 중단된 체크포인트.
- `tmp/heard-ko-retrieval64/`, `tmp/heard-ko-live5/`: 한국어 검색·표본 응답.
- `tmp/memops-adjacent-live5/`: 인접 대화 표본의 원문/추출 비교.
- `tmp/benchmark-independent-judge/`: 대조 문항·부분 재채점·할당량 진단.

평가 도구의 자동 검사 21개가 통과했다. 정보 누출 방지, 과거 assistant 발화 검색, 미래/다른 인물 발화 제외, 세션/발화 hit 구분, Unicode JSONL, 공식 prompt 함수 일치, 일일 quota 재시도 금지 등을 검사했다. 이는 모델의 정답 정확도 검사를 대신하지 않는다.
