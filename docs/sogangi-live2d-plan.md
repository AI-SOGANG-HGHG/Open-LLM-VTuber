# 서강이 Live2D 제작 설계

작성: 2026-10-30, 11월 3일 후속 반영. 전체 제작 규격은 초안이다. 눈·입 기준 모델, 작은 정면 기울기/호흡 모델과 오른팔 인사 모델을 만들었다. 후속 표정 모델에 중립·기쁨·화남·놀람을 연결했으며 기본 대화 화면은 표정 모델이다. 또한 SVG 선택/복구도 지원한다. 디포머 계층·입체 회전·손가락 분할과 나머지 감정 원화는 남아 있다. [Live2D 대화](http://localhost:12393/web-tool/sogangi/?avatar=live2d), [표정 모델 검수실](http://localhost:12393/web-tool/sogangi/live2d-preview.html?model=sogangi-expressions)과 [재현·검수 범위](sogangi-rigging-integration.md)를 참고한다.

공식 자료는 2023-11-10 서강가젯의 리뉴얼 소개를 기준으로 한다. 서강이는 알바트로스 모자와 교표 형태의 옷을 입은 캐릭터이며 새 모양 캐릭터 알로스와 구분한다. 기본형과 기쁨·사랑·발견·가르침·화남·빼꼼·응원을 참고한다. Python 다운로드의 인증서 문제가 있었으나 Windows 인증서 저장소를 사용하는 다운로드로 공식 PDF 23쪽을 확보했다. 캐릭터는 PDF 19–20쪽에 벡터로 들어 있다.

원본의 사용·변형 범위를 학교 UI 안내와 대조해 기록한다. 도형 비율, 모자의 부리와 날개, 의상 문양을 임의로 새 캐릭터로 바꾸지 않는다. 자동 배경 제거·이미지 생성 결과를 공식 벡터 원본이라고 부르지 않는다.

## 첫 모델 범위

정면 기본형 전신 한 개로 시작한다. 먼저 눈 깜빡임, 입 벌림, 작은 호흡, 좌우 기울기와 인사만 구현한다. 큰 회전·걷기·손가락·물리 흔들림은 첫 납품에 넣지 않는다. 레이어 PSD는 투명 배경, RGB 8bit, 2048×2048 캔버스를 작업 규격 초안으로 제안한다. 원본 해상도와 실제 렌더 품질을 보고 확정한다.

모자와 몸통 문양은 서강이를 알아보는 주요 요소다. 호흡이나 고개 회전으로 문양이 과하게 늘어나지 않도록 독립 파츠 또는 약한 변형 계층을 사용한다. 얼굴은 모자 아래 가려진 부분까지, 팔은 몸통에 가려진 어깨까지 그려서 움직일 때 빈틈이 드러나지 않게 한다.

## 원화 레이어 분리안

아래는 실제 분리된 파일 목록이 아닌 PSD 제작용 레이어 명세다. PSD 안의 영문 이름은 고정하고 사람이 읽는 한국어 라벨을 함께 관리한다.

| 그룹 | 분리할 레이어 | 움직임과 겹침 기준 |
| --- | --- | --- |
| `Hood` | `Back`, `Front`, `WingL`, `WingR`, `BirdEyeL`, `BirdEyeR`, `Beak` | 얼굴을 감싸는 앞·뒤와 좌우 날개 분리. 부리·새 눈 위치는 모자에 고정. |
| `Face` | `Base`, `CheekL`, `CheekR` | 피부는 모자 아래까지 이어 그림. 볼은 표정 강도만 소폭 조절. |
| `EyeL`, `EyeR` | 각각 `Open`, `Highlight`, `Closed` | 검은 눈과 하이라이트, 감은 눈 모양 분리. 흰자나 새로운 장식을 임의로 추가하지 않음. |
| `Mouth` | `Closed`, `Open`, `Inner` | 기본 미소와 공식 기쁨 표정을 기준으로 입 벌림 제작. 말하기와 표정의 제어 충돌을 방지. |
| `Body` | `Base`, `Tunic`, `Emblem` | 의상과 문양 분리. 몸의 호흡을 주되 문양은 형태 유지. |
| `ArmL`, `ArmR` | 각각 `Base`, 필요 시 `Hand` | 처음에는 어깨 기준 단순 회전. 복잡한 손 동작은 후속 원화 확장. |
| `LegL`, `LegR` | 각각 `Base`, `Foot` | 몸통 뒤까지 겹침을 확보. 첫 버전은 거의 고정. |

권장 계층은 전체 위치→몸통→머리/모자→눈/입이며 팔·다리는 몸통을 따른다. 레이어 표시 순서와 가림은 위 표의 이름 순서로 자동 결정하지 말고 정면 합성 결과로 검토한다. 분리 전후 정면 합성 이미지를 겹쳐 원본과 실루엣·색·문양이 유지되는지 확인한다.

## 파라미터 명세

표의 값은 제작 초안이다. Cubism 표준 ID를 우선하고 앱에서 실제로 구동되는지 납품 모델로 확인한다.

| 파라미터 | 범위 / 기본 | 역할 |
| --- | --- | --- |
| `ParamAngleX`, `ParamAngleY`, `ParamAngleZ` | -30..30 / 0 | 작은 고개 방향·기울기. 첫 동작의 사용 폭은 중앙 부근으로 제한. |
| `ParamEyeLOpen`, `ParamEyeROpen` | 0..1 / 1 | 눈 깜빡임·기쁜 눈. 두 눈을 따로 조절 가능하게 제작. |
| `ParamMouthOpenY` | 0..1 / 0 | 재생 중 음성 크기에 따른 입 벌림. |
| `ParamMouthForm` | -1..1 / 0 | 미소와 입 모양 변화. 발화 시 벌림 제어를 덮어쓰지 않음. |
| `ParamBreath` | 0..1 / 0 | 작은 몸통 호흡. 의상 문양 왜곡 최소화. |
| `ParamBodyAngleZ` | -10..10 / 0 | 몸 기울기. 발의 접지와 실루엣 유지. |
| `ParamArmRWave` | 0..1 / 0 | 화면 오른팔 인사. 실제 SVG 동작과 PSD 좌우 기준에 맞춘 커스텀 파라미터. |

`model3.json`의 `Groups`에 `EyeBlink`와 `LipSync`를 선언한다. 새 모델의 입은 `ParamMouthOpenY`로 설계한다. 현재 예제 Mao 모델은 LipSync 그룹에 `ParamA`를 사용하므로 그 이름을 서강이 규격에 그대로 복사하지 않는다. 현재 웹 런타임의 실제 파라미터 구동 경로도 검증해야 한다.

## 움직임과 표정

| 상태·동작 | 설계 | 완료 기준 |
| --- | --- | --- |
| Idle | 4–6초 호흡 루프, 자연스러운 눈 깜빡임 | 눈·입·문양이 찌그러지거나 레이어 틈이 보이지 않음 |
| Waiting | 고개를 아주 조금 기울이고 호흡 유지 | 오래 기다려도 과하게 반복하거나 발화를 가장하지 않음 |
| Speaking | 오디오 크기에 따라 입 벌림, 몸은 소폭 움직임 | 음성 시작·정지·음소거·중단과 입 움직임이 함께 멈춤 |
| Greet | 약 1.5초 팔 인사 후 기본 자세 복귀 | 마지막 프레임이 Idle과 자연스럽게 연결 |
| Cheer | 공식 응원형을 참고한 작은 긍정 동작 | 반복 횟수를 제한하고 대화 입력을 막지 않음 |
| Interrupt | 진행 중 발화와 동작을 취소하고 중립 복귀 | 다음 요청에서 이전 음성·표정이 재등장하지 않음 |

첫 표정 목록의 순서를 `neutral`, `joy`, `sadness`, `surprise`, `anger`로 고정한다. `.model3.json` Expressions 배열 순서와 `model_dict.json`의 인덱스를 맞춘다. 백엔드의 여덟 감정 키는 아래처럼 연결할 수 있다.

```json
{"neutral":0,"joy":1,"smirk":1,"sadness":2,"surprise":3,"fear":3,"anger":4,"disgust":4}
```

감정별 입 벌림 값을 계속 고정하면 립싱크를 덮어쓸 수 있다. 표정은 눈/볼/입 모양 중심으로 만들고 입 벌림은 재생 중 음성 제어에 맡긴다. 현재 이미지 시제품의 표정 전환과 Live2D 파라미터 재생은 서로 다른 구현이다.

## 납품과 앱 연결

편집 원본 PSD·cmo3와 실행 묶음을 따로 보존한다. 실행 묶음의 제안 구조는 다음과 같다.

```text
live2d-models/sogangi/runtime/
  sogangi.model3.json
  sogangi.moc3
  sogangi.cdi3.json
  textures/texture_00.png
  expressions/neutral.exp3.json ... anger.exp3.json
  motions/idle.motion3.json
  motions/greet.motion3.json
```

물리 파일과 포즈 파일은 사용한 경우에만 포함한다. `.model3.json`이 참조하는 모든 상대 경로가 실제 파일과 일치해야 한다. Cubism Editor 최신 버전으로 내보낼 수 있다고 현재 앱의 Cubism Core에서 읽힌다고 가정하지 않는다. 현재 런타임에 맞는 내보내기 버전을 작은 모델로 먼저 확인한다.

모델이 준비된 뒤 `model_dict.json`에 `name: sogangi`, 실제 model3 URL, 화면 배율, Idle 그룹, 감정 매핑을 추가한다. 실제 모델 로드가 확인된 후에 `characters/ko_sogangi.yaml`의 필수 fallback `mao_pro`를 `sogangi`로 변경한다. 현재 fallback 이름만 바꾸면 존재하지 않는 모델 때문에 설정 전환이 실패하므로 미리 변경하지 않는다.

## 제작 단계별 종료 기준

1. **원본 단계:** 공식 벡터/고해상도 원화와 사용 조건을 확보하고 출처·버전을 기록.
2. **분리 원화 단계:** 레이어 PSD, 정면 합성 비교, 가려진 부분의 보완, 좌우 이름·피벗 표시 완성.
3. **최소 리깅 단계:** 눈·입·호흡·기울기 한 세트와 cmo3 원본, 작은 실행 묶음 완성.
4. **앱 연결 단계:** 브라우저에서 실제 모델 표시, 음성 립싱크, 표정 인덱스, 중단 후 복귀 확인.
5. **확장 단계:** 인사·응원과 선택적 시선·물리. 약한 PC와 모바일에서 프레임·메모리 확인.

현재 완료는 이미지 시트·공식 PDF 벡터·SVG 파츠와 이를 변환한 준비용 PSD·PNG 24개, Editor 가져오기·눈/입과 작은 정면 기울기/호흡 키폼, 대화 오디오 연결이다. 준비 PSD를 공식 편집 원본이나 리깅 완성 원화로 부르지 않는다. 다음 제작 작업은 가려진 부분과 표정 중간 원화 보완, 디포머 계층·입체 회전과 팔 인사다. 파일과 검증 범위는 [원화 인계 자료](sogangi-art-handoff.md)와 [확장 모델 기록](../live2d-models/sogangi-motion/verification.json)에 있다.

SVG 추출은 `tools/export_sogangi_vectors.py`로 재현한다. PDF의 원래 도형을 유지하고 페이지 글자를 제외한 뒤 표시 영역만 지정한다. 원본 PDF의 SHA-256과 페이지·좌표는 `web_tool/sogangi/assets/sogangi-vector-source.json`에 있다. 원본 PDF는 `tmp/sogangi-reference/Sogang_UI_renewal.pdf`에 보관했다.

보이는 파츠 분리는 `tools/prepare_sogangi_layers.py`로 재현한다. 원본 PDF의 해시를 고정하고 원래 채우기·외곽선·클리핑·그리기 순서를 보존한다. 기본 파츠 21개에는 열린 눈/하이라이트, 닫힌 입, 얼굴/볼, 모자/날개/부리, 의상/문양, 팔다리가 포함된다. 공식 기쁨형의 감은 눈 2개와 열린 입 1개도 원래 얼굴 비율에 맞춰 정렬해 후보로 추가했다. 기본 합성에서는 후보를 숨기며, 각 SVG는 같은 좌표·캔버스를 사용한다. 11월 2일에는 별도 `tools/export_sogangi_psd.py`로 보이는 파츠 준비 PSD를 만들고 실제 Chrome 렌더와 레이어 왕복 검사를 추가했다.

PSD 작업에서는 SVG의 같은 캔버스와 좌표를 유지하고, 투명 영역을 제각각 잘라 정렬 정보를 잃지 않게 한다. 제안한 2048×2048 작업 캔버스에는 원본 비율을 유지해 배치한다. 정사각형으로 강제 변형하지 않는다. 표정 후보는 메시 변형과 자연스러운 중간 모양을 원화 담당자가 검토해야 한다.

SVG 모드에서는 `SvgMascot`이 SVG 파츠의 눈 깜빡임·작은 기울기·오디오 크기에 따른 입 벌림을 재생한다. 이 SVG 동작은 Cubism 리깅과 구분한다. 기본 Live2D 모드는 `AvatarRenderer`가 실제 MOC3의 눈·입을 제어한다. 설계 화면의 수동 슬라이더는 SVG 후보 검토이며 실제 Core 조작은 별도 모델 검수실을 사용한다.

## 10월 30일 시각 품질 피드백 반영

사용자는 초기 화면이 기존 Mao Live2D 화면보다 완성도가 낮다고 지적했다. 기능 연결 성공과 캐릭터 표현 품질을 별도로 평가한다. 초기 시제품은 큰 소개 문구, 섬세한 배경과 평면 캐릭터의 밀도 차이, 약한 접지와 제한적인 파츠 동작이 문제였다.

현재 화면은 큰 소개 문구를 제거하고 캐릭터를 확대했으며, 단순한 캠퍼스 벡터 배경과 발밑 그림자를 적용했다. 호흡은 발을 띄우는 이동 대신 발밑을 기준으로 작은 크기 변화로 바꿨다. 시선 이동과 짧은 웃는 인사·팔 동작은 SVG 파츠 시제품에서 구현했다. 이것을 실제 Live2D 제작 완료로 간주하지 않는다.

실제 모델 제작 시 기존 Mao와 같은 창 크기로 나란히 비교하고 다음 항목을 검수한다.

| 항목 | 검수 기준 |
| --- | --- |
| 정면 원화 | 공식 원화의 얼굴 비율·외곽선·색·의상 문양을 기준으로 비교. 배경과 UI를 끄고 단독 확인. |
| 화면 존재감 | 얼굴과 후드가 UI에 가려지지 않으며 캐릭터·입력창을 데스크톱과 모바일에서 함께 볼 수 있음. |
| 접지 | 호흡·발화·인사에서 발이 바닥을 미끄러지거나 떠오르는 인상을 주지 않음. 그림자가 발 위치와 일치함. |
| 눈과 입 | 깜빡임 중 눈동자/하이라이트가 튀지 않음. 입은 닫힘·작은 벌림·큰 벌림의 중간 모양을 만들고 음성 종료/중단 시 닫힘. |
| 고개와 후드 | 정면→기울기에서 얼굴·볼·후드·부리의 상대 위치가 유지되고 틈이나 겹친 외곽선이 보이지 않음. |
| 팔 인사 | 어깨의 가려진 부분을 보완하고 끝 자세에서 손이 분리되거나 후드 안으로 사라지지 않음. 천천히 진입·복귀함. |
| 표현 차이 | Idle·Waiting·Speaking·Greeting을 움직임만 보고 구별할 수 있으면서 계속 과장된 반복을 하지 않음. |
| 접근성 | 움직임 줄이기에서 호흡·시선·인사와 부차 동작을 멈춤. 음성 립싱크·중단 동작은 유지함. |

검수 캡처는 정면·눈 감음·입 벌림·좌우 기울기·인사에서 각각 남긴다. PSD의 숨은 부분 보완과 Cubism 메시 변형이 없는 현재 SVG 검증만으로 이 표 전체를 통과했다고 기록하지 않는다.
