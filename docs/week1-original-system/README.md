## 서강이 작업본과 원본을 구분하는 이유

현재 브랜치는 서강이 화면·캐릭터뿐 아니라 서버도 수정한 상태다. 원본 화면인 `/`를 열어도 실행 중인 서버가 이 브랜치라면 수정된 백엔드를 사용한다.

원본 대비 현재 `1d1dc02`까지의 변경에는 연결별 Agent 생성, 요청 중단·식별, 음성 완료 처리, 기록 저장과 로그 처리 등이 포함된다. 원본 시스템 이해는 고정 커밋에서 진행하고, 서강이는 이후 변경 효과를 비교하는 자료로 사용한다. 기존 작업 폴더의 브랜치를 되돌리지 않고 별도 폴더에서 원본을 확인한다.

## 현재 합의한 진행 방향

- **1주차:** 각자 오픈소스를 확인하고 결과를 공유한다.
- **2~4주차:** 페르소나·RAG / 방송 연동·프론트엔드 / 게임 연동의 세부 팀으로 나누어 공통 설계를 진행한다. 목표는 4주차 정도까지 공통 설계를 마치는 것이다.
- **5주차 이후:** 공통 기반을 바탕으로 소규모 팀·개인 연구 개발을 진행한다.

세 팀의 데이터 형식을 초반에 합의하고 4주차에 최소 연동을 확인하자는 내용은 제안이다. 구체적인 역할·인터페이스·완료 기준은 팀이 결정한다. 기존 `docs/plan.md` 등의 첫 1~2주 설계안과 일정 표현이 다르면 위 사용자 최신 방향을 우선한다.

## 이 자료에서 확인한 수준

- **확인함:** Git 이력과 원본 소스의 정적 분석, 현재 브랜치와의 코드 차이.
- **이번 작업에서 실행하지 않음:** 원본 의존성 설치, 서버 기동, 실제 API·마이크·스피커·Live2D 재생.
- **직접 채울 내용:** 다른 PC에서의 실행 결과와 오류, 관찰한 응답·기억·음성 동작.

이번 자료에는 API 키나 개인 대화, 기존에 추적되지 않은 기획안 파일을 포함하지 않는다.
