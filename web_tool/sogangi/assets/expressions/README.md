# Official face-part preparation

Generated by `tools/prepare_sogangi_expressions.py` from the pinned official UI guide PDF and the preserved 24-layer import PSD. The baseline layers retain their exact pixels, offsets and visibility. Five hidden layers are added from page 20: anger eyes (drawings 50/51), closed mouth (47), and discovery mouth (203, reused for both open variants). Each is aligned by the corresponding official face bounds; indices, transforms and hashes are in `import-manifest.json`.

The 29-layer, nine-group PSD is preparation generated by this project, not an official layered source. Its neutral composite is unchanged. Native rig/export/browser verification is separate in `live2d-models/sogangi-expressions/verification.json`. Angry-open aspect changes and surprise eye widening are project keyform adaptations, not newly discovered official variants. Source artwork rights remain with Sogang University/relevant owners.
