# Asset provenance

- `sogangi-official-sheet.jpg`: unmodified official Sogang University character sheet, published in Sogang Gazette on 2023-11-10. Retrieved 2026-10-29 from `https://pr.sogang.ac.kr/dataview/board/264/20231110_1411_4510001.jpg`, with the article as Referer. The webpage uses SVG viewports to show the existing poses; this is an image prototype, not a Live2D model. Copyright belongs to the original rights holders. The backend's MIT license does not grant rights to this university character asset.
- Official article and character credit: https://pr.sogang.ac.kr/front/boardview.do?bbsConfigFK=264&pkid=901406
- University UI guide: https://www.sogang.ac.kr/intro/symbol/data/Sogang_UI_renewal.pdf . Retrieved with Windows certificate validation after the Python certificate check failed. The local original is in ignored `tmp/sogangi-reference/Sogang_UI_renewal.pdf`; it is not bundled into the public page.
- `sogangi-{neutral,joy,love,discovery,teaching,anger,peek,cheer}.svg`: original character vector paths from official PDF pages 19-20, exported by `tools/export_sogangi_vectors.py`. Page text is excluded and the SVG viewport selects each existing pose. No character artwork is generated or redrawn. These are vector references, not a layered PSD or a Cubism model. The source checksum and viewports are recorded in `sogangi-vector-source.json`.
- `project-room.png`: generated for this student prototype with the imagegen skill on 2026-10-29. It depicts an imagined warm campus project room, not a documented building of Sogang University. No additional character artwork is generated into the scene.
- `campus-lounge.svg`: current background, drawn as native SVG on 2026-10-30. An imagined campus lounge with restrained colors and simple shapes to match the mascot. It does not depict an actual university building. Replaces `project-room.png` in the main prototype; the earlier raster is kept as a reference.
- `layers/` and `sogangi-visible-parts.zip`: 21 base vector parts plus 3 expression candidates (closed eyes and an open mouth) from the official joy pose, a composite SVG and preparation manifest. The candidates are uniformly aligned to the neutral face, and hidden by default. The neutral composite render is pixel-identical to the reference export. Missing overlaps, artist review of the candidates, PSD organization and Cubism rigging remain. Extraction uses `tools/prepare_sogangi_layers.py` and the pinned official PDF.
- `production/`: preparation PSD, 24 transparent PNG layers, manifest, preview and ZIP generated on 2026-11-02 by `tools/export_sogangi_psd.py`. These are format conversions of the existing official vector parts using Chromium; not official layered source files, new underpainting or a Cubism rig. The PSD was reopened and layer pixels/visibility/alignment and transparent composite preview checked. Photoshop/Cubism import is unverified. See `docs/sogangi-art-handoff.md`.

Before a public release, record the permitted university-character uses and any required attribution or adaptation conditions. Do not describe the official sheet as MIT-licensed or as original artwork by this team.

`expressions/` is a separate 29-layer preparation PSD with five hidden face parts extracted from the pinned official PDF anger/discovery poses. The existing 24 layers remain unchanged. Original curves/alignments are recorded in its manifest; angry-open aspect changes and surprise eye widening are project keyform adaptations. The resulting native rig and four exp3 files are in `live2d-models/sogangi-expressions/`; this does not make the source art or project adaptations an official university model.
